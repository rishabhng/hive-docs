## Add the connector

1. Go to [grok.com/connectors](https://grok.com/connectors).
2. Choose **New Connector**, then **Custom**, and enter the endpoint:

   ```
   https://mcp.hiveintelligence.xyz/mcp
   ```

3. Choose OAuth and complete authorization in the browser.

## Verify

Start a new conversation and ask Grok for a live crypto price using Hive. The response
should cite a provider rather than answering from training data.

<Note>
  If your organization hides Custom connectors, an admin has to allow Hive before the
  option appears.
</Note>
