<Update label="September 2026" description="1.9.0: failed calls are refunded">
  A call that fails no longer costs anything. On a keyed lane the credit a failed call used is
  refunded: the receipt reads `credits_used: 0`, `credits_remaining` shows the restored
  balance, and `warnings` says the credit was refunded. On the keyless lane a failed call gives
  its daily call back, including one rejected for bad arguments. A scheduled monitor run is
  refunded when it errors or when every tool call in it fails.

  Hive Archive responses now date each dataset from its own start. Funding settlements go back
  to November 2023; basis starts in March 2025, open interest and liquidations in April 2025,
  and the long/short ratio in March 2026. Earlier copy said every series went back to November
  2023.
</Update>

<Update label="September 2026" description="1.8.0: every vendor tool tested from production">
  Every vendor tool was run from production, and the failures that were Hive's own are fixed.
  `alchemy_simulate_execution` sends its arguments in the order Alchemy expects,
  `tenderly_suggest_gas_fee` calls the right gateway method, Tenderly gateway calls retry when
  they are rate limited, DeFiLlama price charts accept a start and an end together, and
  `hyperliquid_get_token_details` accepts a spot token name such as `HYPE`.

  Alchemy's Solana DAS and Photon tools fall back to Helius when Alchemy's indexer is
  unavailable. The response says so: `_hive.source` reads `fallback`, and a `_fallback` block
  names the provider that answered.

  Errors now carry the provider's own message, so a malformed address or an unsupported input
  comes back as `invalid_input` rather than looking like an outage.

  Twenty-one tools that fail on every call on Hive's current data plans are retired: five
  CoinGecko Enterprise tools (supply charts and coin insights), seven DeFiLlama Pro tools
  (derivatives volumes, categories, oracles, forks, and entities), three Helius wallet-identity
  tools, two Alchemy bundle simulations, three CCXT current borrow-rate tools, and GoPlus Solana
  pre-execution. Calling one returns `TOOL_RETIRED` with a working replacement. The catalog is
  now 525 callable tools across ten categories.
</Update>

<Update label="September 2026" description="1.7.0: prediction markets, market signals, one umbrella skill">
  Prediction markets return as a first-party category on Polymarket, not a resold feed: seven
  keyless tools for market and event search, market-implied odds, CLOB order books, bounded
  odds history, and a wallet's positions and activity, plus the `prediction_markets` task
  toolset, the restored `hive-prediction-markets` skill pack, and the `prediction_market`
  monitor kind. Kalshi is not covered, because its developer agreement requires prior written
  authorization before its API data is shared with anyone else.

  Four market-signals tools landed: `signals_get_fear_greed` (Crypto Fear and Greed, current
  plus daily history), `signals_get_technical_indicators` (RSI, MACD, Bollinger, EMA and SMA
  that Hive computes from CoinGecko candles and reports the candle interval for),
  `signals_get_onchain_metrics` (daily Bitcoin hash rate, active addresses, transaction count
  and price), and `defillama_get_hacks`.

  Every receipt now says what the call cost: `credit_cost`, `credits_used`, and
  `credits_remaining`, with a `doc_url` on every error. `report_feedback` is a free write that
  works on the keyless lane, so an agent can report a gap without an account.
  `GET /api/v1/quota` reads today's keyless allowance without spending one.

  The CLI gained generated `--<param>` flags on `hive tools call`, a parameter table in
  `hive tools info`, `hive routing install|decline|remove` for the AGENTS.md routing block,
  `hive feedback`, the `hive archive` namespace, and exit code 6 with no retry on every
  allowance or quota code.

  Skills are now led by one umbrella pack, `hive`, which picks the transport and loads the
  rest. Eighteen packs ship. The catalog is 546 callable tools across ten categories and 15
  providers.
</Update>

<Update label="September 2026" description="1.6.0: Codex.io removed, vendor refresh">
  The Codex.io provider is gone, and with it the Prediction Markets category, its category
  endpoint, the `hive-prediction-markets` skill pack, and the `prediction_market` monitor kind.
  Calls to a retired tool name return a classified not-found error that names the replacement.
  CoinGecko gained the seven tokenized real-world-asset endpoints (`get_rwa_list`,
  `get_rwa_markets`, `get_rwa_asset`, `get_rwa_tickers`, `get_rwa_market_chart`,
  `get_rwa_issuers`, `get_rwa_issuer`), Hyperliquid gained `hyperliquid_get_outcome_deployer_limits`,
  and Helius gained the Parsed Events API (`helius_get_parsed_events_transactions`,
  `helius_get_parsed_events_transaction_history`). Eight Alchemy NFT tools that Alchemy retires
  on 2026-09-30 were removed ahead of the sunset. The catalog is now 534 callable tools across
  nine categories and 12 providers. `hive portfolio balance`, `hive portfolio history`, and
  `hive network chains` now route through Alchemy and CoinGecko.
</Update>

<Update label="August 2026" description="MCP, CLI, and skills only">
  Hive is now an agent-focused product. The REST API remains as internal plumbing for the
  CLI and dashboard, but it is no longer a documented product surface, and the SDK guides
  have been retired.

  Documentation moved here from the main site.
</Update>

<Update label="August 2026" description="Hive Archive provider">
  Added cross-venue derivatives history from 33 CEX and DEX venues: settled funding rates
  back to November 2023, plus basis (from March 2025), open interest and liquidations (from
  April 2025), and long/short ratio (from March 2026). This entry first said every series
  went back to November 2023; only funding does.
</Update>

<Update label="August 2026" description="CLI 1.4.0">
  `hive-intelligence` 1.4.0 is on npm and the hosted runtime serves it. It fixes
  `hive auth login`, which previously failed on every attempt, and stops login minting a new
  API key each time you sign in. Sign-in now also accepts GitHub and Google, and the email path
  sends a 6-digit code as well as a link. `hive auth signup` and the `hive keys` group are
  retired: manage keys in the dashboard. Run `hive upgrade` to move an existing install.
</Update>

<Update label="August 2026" description="CLI 1.3.0">
  The `hive-intelligence` 1.3.0 release ships the CLI with `hive init --all --browser`, which
  detects installed clients and writes their config for you.
</Update>

<Update label="August 2026" description="Anonymous lane">
  Added 25 material calls per IP per day with no account, so Hive can be evaluated before
  signup. Discovery calls do not count against the cap.
</Update>

<Update label="August 2026" description="Compact root endpoint">
  The root endpoint exposes eight tools rather than the full catalog: five workflow
  primitives plus three hero tools. Everything else is reached through discovery.
</Update>
