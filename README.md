# Hive Intelligence docs

Documentation for [Hive Intelligence](https://www.hiveintelligence.xyz), a crypto data layer
for AI agents. Published with [Mintlify](https://mintlify.com) at
[docs.hiveintelligence.xyz](https://docs.hiveintelligence.xyz).

## Local preview

```bash
npx mint@latest dev
```

## Before you push

```bash
npx mint@latest validate
npx mint@latest broken-links
```

Mintlify deploys from `main` on push.

## Editing

Pages are MDX with YAML frontmatter. Navigation lives in `docs.json`; a new page must be
added there or it will not appear.

See `AGENTS.md` for writing rules and where product facts come from.
